# HanuAI Insight Engine

AI-powered Customer Voice & Field Failure Intelligence platform built with Streamlit.

## 🚀 Live Deployment

**Streamlit App:**  
https://hanuai-insight-engine.streamlit.app/

## 📌 Project Overview

HanuAI Insight Engine analyzes customer feedback and field failure data to identify important patterns, trends, sentiment, components, and potential root causes.

## ✨ Key Capabilities

### 📊 Voice of Customer
- Customer review analysis
- Sentiment analysis
- Aspect-level sentiment
- Customer insights
- Review trends

### 🔧 Field Failure Intelligence
- Failure categorization
- Component analysis
- Root-cause candidates
- Failure trends
- Downtime analysis
- Repair-cost analysis

## 📈 Dashboard

The application provides an overview of:
- Customer Reviews
- Failure Records
- Failure Clusters
- Data Sources

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Data Analysis
- AI / Machine Learning
- Natural Language Processing

## ▶️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/pn200203/hanuai-insight-engine.git
cd hanuai-insight-engine
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

Windows:

```bash
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

Then open:

```text
http://localhost:8501
```
